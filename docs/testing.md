# 测试与验证

## 运行检查

```sh
pnpm check
pnpm exec playwright install chromium
pnpm test:e2e
```

`pnpm check` 依次执行类型生成与检查、单元测试、生产构建。浏览器测试会自动启动临时开发服务；如需验证生产包，可先运行 `pnpm start`，再在另一终端运行 `pnpm test:e2e`。
