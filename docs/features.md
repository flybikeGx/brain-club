# 当前功能

- 七个应用页面、统一导航、响应式布局、浅色 / 深色 / 系统主题、键盘焦点、跳过导航链接及减少动态效果支持。
- 首页：建议练习、真实本地体测概况、七日时长、器械入口、最近记录和证据边界。首次使用显示 0 / 空状态，不注入演示成绩。
- **正念跑步机**：3 / 5 / 10 / 15 / 20 分钟与 1–120 分钟自定义；呼吸或身体感觉锚点；初学者 / 安静模式；Web Audio 轻柔提示音、可选视觉动画、阶段文字提示及频率；暂停、继续、自动结束与提前结束；主观状态、舒适度与自由复盘；手动选择四阶段课程。觉察按钮只记录主动点击，无评分、注意力百分比或惩罚。
- 正念草稿每 5 秒及关键状态变更时写入 IndexedDB。失焦、隐藏及离开页面暂停；刷新后恢复为暂停，后台或关闭页面的时间不算练习。异常强制关闭可能丢失最后约 5 秒的草稿进度。完成记录在一次事务中保存并清理草稿。
- **舒尔特**：3×3 至 6×6；可调字体；已点击数字可选保持原样（默认标准模式）或变灰（辅助模式），配置随记录保存并分别比较，旧记录按原有变灰模式解释；实时、结果和历史用时显示为 `分:秒.毫秒`，总用时取最后一个正确点击的单调时钟时间；逐个目标反应时可选；错误、总用时与完成判定；下一次网格大小的保守建议（用户可改）。建议的速度阈值是产品设置，不是人群常模。
- **数字记忆**：正向、反向、动态更新（保留末尾 N 位）；数字展示、作答和反馈使用固定布局，顶部状态、提示和进度条不随阶段切换移动；提供 0–9 屏幕键盘、退格、清空与提交，支持与实体键盘混合输入及光标位置编辑，移动端不自动弹出系统键盘；可调展示间隔；10 个正式试次；每两题按正确率调整长度；训练即时反馈和学习曲线。
- **二维旋转**：题号、目标、选项、解析和操作区使用固定布局；答对自动进入下一题，答错才标出正确选项并等待手动继续；最后一题答对直接保存，答错确认解析后保存；防止双击与按键长按误答后续题目，失焦恢复时保留错题解析状态；新反馈协议随配置记录，与旧训练条件分开比较。种子化生成相连方块组成的不对称图形，SVG 显示；多种旋转角度与镜像干扰；复杂度和选项数可调；每两题调整复杂度；10 题、正确率和反应时。生成时排除与镜像等价的图形，验证唯一正确选项。
- **体测中心**：顺序 / 倒序数字广度、Corsi-like 空间广度、PVT-like 警觉性短测及阅读理解。所有项目有说明、版本、练习与正式阶段、计分与测量限制。
- 广度：1 次练习 + 8 次正式试次；长度 3 起步，900ms 呈现周期；同长度连续两次正确或错误才调整难度。正式阶段不显示答案或逐题正误；最大广度只取正式试次中正确复现的最长序列。空间序列在九宫区域内随机抖动布局，每串不重复位置。
- PVT-like：3 个练习刺激；默认 3 分钟，另有 1 分钟演示和 5 分钟；间隔 2–5 秒；1500ms 超时；100–1500ms 有效反应、>500ms 迟缓、<100ms 预期性反应；遗漏、抢答、分布、中位数单列。结束时尚未完成的刺激单列为截断，不计为遗漏。测评窗口失焦、隐藏或刺激计时明显延迟时标记无效。
- 阅读：1 道独立练习、2 篇原创示例各 3 题，可回看文本。材料 ID / 版本入库；没有伪装成无限题库。逐题时间是从正式阶段开始到最后一次选答的累计时间，不是剔除阅读时间后的单题反应时。
- 本地历史、逐题操作、种子和版本详情；正确率与速度分别绘图，按相同生成版本、变式和初始配置比较，另有逐题难度轨迹、最近 3 次与此前均值的对照。至少各有 3 条速度数据才显示均值对照；不做显著性判断。
- JSON 导出、导入前格式校验、单事务合并、同 ID 更新，以及输入确认文字后删除全部本机记录 / 草稿 / 偏好。
- 无外部字体、图片或数据 API；题目、评分、图表在客户端执行。
